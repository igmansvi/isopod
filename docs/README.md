# Isopod Documentation

Welcome to the Isopod technical documentation directory. This folder contains deep-dive materials regarding the system's architecture, design decisions, and shared assets.

## Contents

- **[System Architecture](./architecture.md)**: A detailed breakdown of how the [Angular](https://angular.dev/) Frontend, [Spring Boot](https://spring.io/projects/spring-boot) Backend, and [Docker](https://www.docker.com/) daemon interact, including data flow, terminal WebSockets, and bind-mounting mechanics.
- **[Assets](./assets/)**: Shared media files (such as the Isopod logo) used across the project documentation.
